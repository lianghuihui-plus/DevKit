# MAVT MCP Optimization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace manual Agent invocation plumbing with a production MCP interface without losing MAVT behavior or degrading the measured offline call path.

**Architecture:** One local stdio MCP router; pinned runtime services reuse existing domain implementations. Explicit scoped bindings route every request, including old-version compatibility, without a mutable global current execution.

**Tech Stack:** Node.js built-ins, JavaScript, JSON Schema, Markdown; existing platform tooling unchanged.

**Spec:** `docs/mcp-optimization-design.md`
