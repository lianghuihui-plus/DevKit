# 人工用例质量问题清单

> 来源：编程猫在线APP（41条）+ AI精灵单条语音播放需求（67条）原始 `source.md` 对比分析。

## 前置条件

### PO-001 与步骤起点矛盾

前置条件声明"已在X页面"，但步骤从"启动App"等冷启动动作开始。

**检测**：前置含"已在/已进入X页面"，步骤第1步为"启动App"/"打开应用"。

**示例**：
```
❌ 前置：已在智能体二级页面
   步骤1：启动编程猫在线 App
✅ 前置：测试账号已登录
   步骤1：启动编程猫在线 App
   步骤2：点击底部"首页"TAB
   步骤3：点击"AI智能体"区域...
```

### PO-002 缺少必要的前置条件

步骤操作依赖账户状态、数据配置，但前置条件未声明。

**检测**：步骤含"已登录"相关操作（点击TAB/查看内容）但前置未提及登录。

**示例**：
```
❌ 前置：（空）
   步骤：点击底部"创作"TAB，点击"我的作品"
✅ 前置：测试账号已登录
```

### PO-003 "无额外业务前置条件"占位冗余

这句话本身不提供任何信息，写了等于没写。

**检测**：前置条件内容为"无额外业务前置条件"。

**示例**：
```
❌ 前置：无额外业务前置条件
✅ 前置：（留空）或补充实际条件
```

### PO-004 混入环境/脚本条件

设备型号、系统版本、网络状态属于环境探测（`probe-env.sh`），不应写入前置条件。

**检测**：前置含"设备"/"系统版本"/"网络"/"接口响应"等关键词。

**示例**：
```
❌ 前置：网络正常、接口响应正常
✅ 前置：测试账号已登录
   （网络/接口由环境探测保障）
```

## 操作步骤

### ST-001 末尾冗余系统检查（100%命中）

"检查：App 未闪退，控制台无未处理异常" + "保存当前页面截图、页面 XML 和关键请求日志"。

- 第一条：AI 无法通过截图判断"控制台异常"，应删除或转为视觉断言
- 第二条：`observe.sh` 自动完成

**检测**：步骤末尾包含"未闪退"/"控制台无.*异常"/"保存.*截图.*XML.*日志"。

**示例**：
```
❌ 步骤8：检查：App 未闪退，控制台无未处理异常
   步骤9：保存当前页面截图、页面 XML 和关键请求日志
✅ （删除全部末尾两条）
```

### ST-002 步骤重复/冗余

连续步骤描述同一操作，常见于"点击TAB"后跟"进入该TAB"/"点击该TAB"。

**检测**：连续两步文本相似度 > 0.7，且不含"预期"/"等待"关键词。

**示例**：
```
❌ 步骤3：点击底部"首页"TAB
   步骤4：点击首页tab
✅ 步骤3：点击底部"首页"TAB
```

### ST-003 被动描述当步骤

"观察""查看""出现"不是可执行动作，AI 无法据此操作。

**检测**：步骤以"观察"/"查看"/"出现"/"记录"开头。

**示例**：
```
❌ 步骤5：观察ai智能体模块展示
✅ 步骤5：定位首页"AI智能体"区域
```

### ST-004 条件分支嵌入步骤

if/else 分支使单条用例存在多条路径，MAVT 无法处理。

**检测**：步骤含"如果.*则"/"若未.*则"。

**示例**：
```
❌ 步骤9：如果出现了弹窗，则点击'使用文字课表'
   步骤10：若未出现弹窗，则直接显示课程列表
✅ 拆为两条独立用例，或通过 globalRules 处理
```

### ST-005 断言模糊

"成功登录""页面正常""进入二级页面"等无法被 AI 通过截图验证。

**检测**：断言（含"检查"/"预期"）内容缺少具体可观察元素（按钮/图标/文字/导航栏）。

**示例**：
```
❌ 检查：成功登录
✅ 预期：底部导航栏显示"首页/课程/创作/我的"四个TAB，左上角显示用户头像
❌ 检查：进入到二级页面
✅ 预期：页面顶部展示"AI精灵"标题，底部展示输入框和发送按钮
```

### ST-006 定位不精确

"任意区域""对应按钮""找到X"等让 AI 无法确定点击目标。

**检测**：操作动作（点击/滑动/输入）+ 含"任意"/"对应"/"相关"/"某个"/"找到"。

**示例**：
```
❌ 找到含有'混合课'文案的课包卡片，点击进入
✅ 点击名称为"混合课"的课包卡片
❌ 点击对应编辑器
✅ 点击"kittenN图形化编程"入口
```

### ST-007 步骤缺失中间操作

步骤链跳跃，缺少导航到目标页面的中间步骤。

**检测**：前置条件声明"已在X页面"但步骤没有从启动到X页面的导航链。

**示例**：
```
❌ 前置：已进入我的作品tab（步骤从启动App开始只写了"点击退出"）
✅ 前置：测试账号已登录
   步骤：启动App → 点击"创作"TAB → 点击"我的作品"入口 → 等待加载 → 点击退出
```

### ST-008 "检查："未统一为"预期："

全域使用"检查："而非 MAVT 规范的"预期："。

**检测**：断言步骤以"检查："开头。

**示例**：
```
❌ 检查：成功登录
✅ 预期：底部导航栏显示，左上角显示用户头像
```

### ST-009 缺少必要的等待步骤

操作后直接断言，未给页面加载/动画/网络响应留时间。

**检测**：操作步骤后紧跟断言，中间无"等待"步骤。

**示例**：
```
❌ 步骤4：点击"登录"按钮
   步骤5：检查：成功登录
✅ 步骤4：点击"登录"按钮
   步骤5：等待登录完成
   步骤6：预期：底部导航栏显示...
```

## 严重度分级

| 级别 | 问题编号 | 说明 |
|---|---|---|
| **P0 阻断** | PO-001, PO-002, ST-001, ST-002 | 不修复用例无法执行或执行结果无意义 |
| **P1 影响可执行性** | PO-003, PO-004, ST-003, ST-004, ST-005, ST-006, ST-007, ST-009 | 降低执行成功率或导致误判 |
| **P2 格式规范** | ST-008 | 格式不统一，不影响执行但需修正 |
