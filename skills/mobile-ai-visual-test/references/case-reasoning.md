# 用例业务判断指南

这些原则用于理解和执行原始用例，不替代原文，也不授权 Runtime 推断业务语义。

1. 保留“若、如果、可选、可能、无需、跳过、直到”等限定词。条件步骤应表达为条件分支，不能强化成无条件验证点。
2. 不扩大或缩小原始用例的业务要求。无法确定时保留不确定项，不自行补全产品规则。
3. 区分“当前画面未满足预期”和“目标在完整可探索范围内不存在”。后者必须完成范围探索。
4. 当前画面只覆盖部分区域时，继续探索、修订计划或形成无法判断，不能直接断言不存在。
5. 实际结果异常时，先检查执行路径、动作位置、观察范围、环境差异和产品结果，再决定下一步。
6. Case Flow 可以根据现场修订；修订时记录触发的新事实或理解变化。
7. 收口前核对原始用例、当前 Case Flow、实际路径和结果，避免条件、可选内容或验证范围发生语义偏移。
